Executive Abstract

Shortest-path finding in spatial networks is among the most foundational problems in computer science, underpinning intelligent transportation systems (ITS), logistics dispatching, and robotic navigation. While textbook asymptotic bounds (O(V+E) vs. O((V+E)log V)) provide critical asymptotic guidance, practical algorithmic behavior is fundamentally shaped by spatial geometry, positive physical edge costs, heuristic pruning, and network bottlenecks.

This project presents RouteX, an academic experimental laboratory designed to evaluate, benchmark, and visualize the five canonical graph traversal and shortest-path algorithms:

  1. Breadth-First Search (BFS) — Blind Level-Order Exploration
  2. Depth-First Search (DFS) — Blind Branch-Diving Traversal
  3. Dijkstra’s Algorithm — Uniform-Cost Minimal Distance Search
  4. A* Search (A-Star) — Heuristically Guided Goal-Directed Search
  5. Greedy Best-First Search — Pure Heuristic Aggressive Search

The system provides a 100% offline, deterministic procedural city road network featuring 100+ intersections, 160+ road segments, and 9 river bridge crossings across 11 metropolitan districts, accompanied by authentic OpenStreetMap (OSM) extracts for Central London, Manhattan, and South Mumbai.

Empirical findings demonstrated in this report include:

  • Admissibility & Consistency Proofs: Mathematically proving that the great-circle Haversine heuristic is admissible and consistent, guaranteeing A* distance optimality.
  • Search Space Pruning: A* reduces node evaluations by 57.6% compared to Dijkstra while achieving the identical optimal distance.
  • Hop-Optimality vs. Distance-Optimality: BFS minimizes intersection turns (4 turns vs. 6 turns), but produces a route that is 18.4% longer in physical travel distance (7,768m vs. 6,560m).
  • Greedy Trap Vulnerability: Greedy Best-First Search commits aggressively to straight-line headings, causing severe entrapment near river corridors.

Chapter 1: Introduction

1.1 Background & Motivation

Navigation and automated route planning represent critical technological pillars of the modern economy. Autonomous vehicles, package delivery couriers, ride-hailing networks, and emergency medical services all rely on graph algorithms to calculate the most efficient route from an origin to a destination.

While theoretical computer science courses routinely cover Dijkstra's algorithm and A* search, students frequently fail to appreciate the physical spatial nuances of road network graph topologies. In particular:

  • Theoretical Big-O worst-case bounds do not distinguish between isotropic radial exploration and goal-directed heuristic pruning.
  • Unweighted graph algorithms (BFS) are often conflated with metric shortest-path algorithms (Dijkstra).
  • Existing educational visualizers rely on live geographic tile servers and public routing APIs, which suffer from rate limits, network timeouts, and lack of deterministic inspection.

2.2 Algorithmic Paradigms

1. Dijkstra's Algorithm: Operates by maintaining a tentative distance value for every vertex. By extracting the vertex with minimum tentative distance from a binary min-heap and relaxing its incident edges, Dijkstra discovers the optimal distance to every reachable vertex in order of increasing cost.

2. A* Search: Enhances Dijkstra's uniform expansion by introducing a heuristic function h(n) representing the estimated cost to reach the target: f(n) = g(n) + h(n). If h(n) is admissible, A* is guaranteed to discover the optimal path while exploring a minimal set of nodes.

3. Greedy Best-First: Sets f(n) = h(n), ignoring the cost g(n) incurred so far. While fast, it easily falls into dead-end traps and local minima when obstacles block the direct line of sight.

Chapter 3: Mathematical Formulations & Proofs

3.1 Spherical Haversine Geodesic Metric

On geographic coordinates, Euclidean distance induces severe distortion. RouteX calculates exact geodesic distances in meters using the spherical Earth model (mean radius R = 6,371,000 meters):

Δφ = φ₂ - φ₁
Δλ = λ₂ - λ₁
a = sin²(Δφ / 2) + cos(φ₁) · cos(φ₂) · sin²(Δλ / 2)
c = 2 · atan2(√a, √(1 - a))
d = R · c (meters)

3.2 Formal Proof of A* Admissibility

Theorem: The great-circle Haversine heuristic is strictly admissible:

0 ≤ h(n) ≤ d*(n, dest), ∀ n ∈ V

Proof: By differential geometry on a spherical surface, the geodesic arc represents the absolute minimum path length connecting two surface coordinates in 3-dimensional space. Any physical road must follow terrestrial street alignments, which are constrained to lie upon the sphere. Therefore:

Length(Any Valid Road Path from n to dest) ≥ d_Haversine(n, dest)

Because the shortest road path d*(n, dest) is a member of the set of all valid road paths, it follows that:

d_Haversine(n, dest) ≤ d*(n, dest)

Hence, h(n) is admissible, guaranteeing A* optimality.

3.3 Proof of Consistency (Monotonicity)

Theorem: The great-circle Haversine heuristic satisfies the consistency condition: h(u) ≤ c(u, v) + h(v).

Proof: By the triangle inequality on metric spaces:

d_Haversine(u, dest) ≤ d_Haversine(u, v) + d_Haversine(v, dest)

Because road segment lengths satisfy c(u, v) ≥ d_Haversine(u, v):

h(u) ≤ c(u, v) + h(v)

Consistency ensures that the evaluation function f(n) is monotonically non-decreasing along any path, guaranteeing that when any node is closed, its shortest path has been permanently established.

4.2 Key Analytical Findings

Finding 1: A* Pruning Efficiency (57.6% Search Reduction)
Both Dijkstra and A* discover the identical optimal path of 6,560 meters. However, Dijkstra expands 33 nodes in an isotropic circular wave, whereas A* expands only 14 nodes, pruning 57.6% of the search space.
Finding 2: Hop-Optimality vs. Metric-Optimality
BFS minimizes intersection turns (4 hops vs. 6 hops), but produces a route that is 18.4% longer in physical travel distance (7,768m vs. 6,560m). This proves that minimizing edge hops is distinct from minimizing physical travel distance in spatial networks.
Finding 3: Greedy Obstacle Entrapment
Greedy Best-First Search rushes toward the destination coordinates. Upon encountering the river barrier without an immediately adjacent bridge, it becomes trapped in dead-end alleys, accumulating 8,240 meters (+25.6% above optimal).
