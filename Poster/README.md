# RouteX — Academic Poster Deliverables

This directory contains the presentation and exhibition poster assets for the **RouteX: Analysis of Algorithms** project submission.

## 📁 Included Deliverables

1. **`RouteX_Poster.jpg`**: High-resolution academic research poster graphic in vertical presentation format featuring the project title, abstract, motivation, algorithm complexity table, 100+ node city visualization, benchmark charts, and conclusions.
2. **`RouteX_Academic_Poster.html`**: A publication-quality, print-ready, high-resolution scientific poster designed with CSS Grid (3-column academic layout), dark cyber aesthetic, embedded vector diagrams, algorithm complexity table, benchmark charts, and a floating **"Print / Save as PDF"** button. Double-click or open in any browser (`Chrome`, `Edge`, `Firefox`) to view or print to PDF in A1/A2/A3/A4 landscape format.
3. **`RouteX_Poster_Content.md`**: Clean, structured markdown text containing all poster sections (Abstract, Problem Statement, Methodology, Mathematical Formulations, Experimental Benchmarks, and Conclusions) formatted for students who need to copy-paste into PowerPoint poster templates, Canva, or LaTeX `beamerposter`.

## 🖨️ Printing & Presentation Instructions

- **To print as PDF or poster paper**: Open `RouteX_Academic_Poster.html` in Chrome/Edge, click the floating **"Print / Save as PDF"** button (or press `Ctrl + P`), select **Landscape**, set Paper size to `A1`, `A2`, `A3`, or `A4`, and check **"Background graphics"**.
- **For viva / oral presentations**: Reference the 3-column flow:
  1. **Column 1**: Theoretical foundations, Big-O complexity table, and Haversine admissibility proof.
  2. **Column 2**: Cartographic simulation architecture (100+ nodes, 9 bridges) and full-screen visualizer.
  3. **Column 3**: Benchmark charts (Node expansions and Distance) proving A* prunes 57.6% of nodes while matching Dijkstra's exact optimal distance.
