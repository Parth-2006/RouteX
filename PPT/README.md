# RouteX — Presentation Deliverables (PPT)

This directory contains the presentation slide deck and speaking notes for the **RouteX: Analysis of Algorithms** viva and seminar defense.

## 📁 Included Deliverables

1. **`RouteX_Presentation.html`**: A full 20-slide interactive presentation web application. Can be run in any browser (`Chrome`, `Edge`, `Firefox`) without requiring Microsoft PowerPoint or internet connectivity. Features:
   - **Keyboard Navigation**: Press `Right Arrow` or `Spacebar` for next slide, `Left Arrow` for previous slide.
   - **Full-Screen Mode**: Press `F` to enter/exit immersive presentation view.
   - **Speaker Notes**: Press `N` to toggle the presenter's speaking notes panel.
   - **Print Handouts**: Press `P` or click **"Print Handouts"** to print or save the slide deck as a PDF document.
2. **`RouteX_Presentation_Slides.md`**: Complete slide-by-slide markdown transcript containing all slide titles, bullet points, data tables, mathematical proofs, and presenter speaking notes.

## 🎤 Presentation Walkthrough (20 Slides)

- **Slides 1–3**: Introduction, Abstract, Motivation, and Research Objectives.
- **Slides 4–7**: Algorithmic Foundations (Uninformed vs. Informed), Theoretical Complexity Matrix, Haversine Geodesic Formula, and Mathematical Proofs of Admissibility & Consistency.
- **Slides 8–11**: System Architecture, 100+ Node Procedural Metropolis, 9 Bridge Corridors, and Real-World OSM Extracts (London, Manhattan, Mumbai).
- **Slides 12–16**: Empirical Benchmarks, Node Pruning (A* vs. Dijkstra 57.6% search reduction), Hop-Optimality (BFS) vs. Metric-Optimality, and Greedy Search Vulnerability.
- **Slides 17–20**: Discrete 2D Grid Visualizer, Engineering Trade-Offs, Conclusions, Future Scope, and Q&A.
