# RouteX — Word Art & Typography Deliverables

This directory contains the typographic Word Art and Conceptual Cloud assets for the **RouteX: Analysis of Algorithms** project submission dossier.

## 📁 Included Deliverables

1. **`RouteX_Word_Art.jpg`**: High-resolution creative typography word cloud graphic formatted as a navigation compass and city road network grid with glowing neon cyber-cyan, emerald, amber, and electric pink text. Perfect for project cover pages, dossier title sheets, and binder inserts.
2. **`RouteX_Word_Art.html`**: A standalone interactive web application featuring an interactive vector Word Art canvas with glowing hover definitions and an **"Export SVG"** / **"Print as Dossier Cover"** button. Double-click or open in any browser (`Chrome`, `Edge`, `Firefox`).
3. **`RouteX_Word_Art.svg`**: Standalone vector SVG graphic file that can be inserted directly into Microsoft Word, LaTeX documents, PowerPoint presentations, or printed at any resolution without pixelation.
4. **`Word_Art_Vocabulary.md`**: Categorized glossary and term taxonomy used in the typographic design (Core Algorithms, Mathematical Foundations, Data Structures, Cartographic Network Geometry, and Empirical Benchmarks).

## 🎨 Design Theme & Symbolism

- **Compass Geometry**: Symbolizes directional navigation and pathfinding in 2D and geodesic spherical space.
- **Concentrated Hub**: Radiates from the central "RouteX" hexagon outwards into algorithmic paradigms (Dijkstra, A*, BFS, DFS, Greedy).
- **Concentric Orbits**: Circular text tracks display fundamental theoretical formulations: Time Complexity $\mathcal{O}((V+E)\log V)$, Admissibility $h(n) \le d^*(n)$, Great-Circle Haversine, and 100+ node metropolis graph metrics.
